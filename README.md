# CampusHub — Git & GitHub Workshop Starter

This is the starter project for the Git & GitHub Essentials workshop.

## Important
- This project is intentionally provided without Git history.
- Students should initialize Git themselves during the workshop.
- The project is a small static HTML/CSS/JavaScript website; coding is not the focus of the workshop.
- Workshop tasks will be provided separately.
- Reference snippets/solutions will be provided separately.

## Workshop Areas
The source files contain small HTML comments marking areas that may be used during workshop exercises. These comments do not contain the solutions.
